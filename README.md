# RailSync
Rail Sync uses real-time and historical railway data such as train speed, delay, location, congestion, and speed restrictions. An ML model predicts the remaining travel time and calculates the ETA. FastAPI delivers results, while PostgreSQL stores data and Redis enables fast real-time updates.
